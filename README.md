# Helpful Admin

## Function

Automate file conversion and prepare photo layouts for printing.

## Overview

A collection of personal tools for everyday administrative tasks, including converting audio and Publisher files and arranging photographs in a Word document.

## Contents

Converting Scripts - Tools for M4A-to-MP3 and Publisher-to-PDF conversion.

Printing Photos - A tool for arranging photographs in a Word document for printing.

## Context and contribution

I developed these tools for personal projects to reduce repetitive work and simplify tasks involving documents, audio files and photographs.

Developed with assistance from ChatGPT. I defined the requirements, adapted and tested the code, checked outputs for errors, and debugged issues.

## How to use

Choose a folder from Contents, then open the individual tool's README for setup instructions, dependencies and input requirements. Python tools need their listed packages and configured file paths. Publisher conversion requires Windows with desktop Microsoft Publisher installed. Check the conversion guide before running the audio tool: it overwrites destination MP3s and deletes successfully converted M4A originals.
